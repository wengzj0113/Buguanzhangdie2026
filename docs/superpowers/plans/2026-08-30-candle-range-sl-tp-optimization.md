# K线范围止盈止损模式优化方案与实施计划

## 一、这次修改的目标

在现有“不管涨跌”EA基础上，新增止盈止损距离计算模式。用户可以选择固定距离模式或上一根已完成K线范围模式；K线范围模式等待突破上一根K线后开首单，并由 `ordertype` 自动绑定循环模式。

## 二、止盈止损模式

### 模式一：固定距离模式

保持现有行为：

- 止损距离由用户设置，默认500点；
- 止盈距离由用户设置，默认500点；
- 不检查K线长度；
- 原有三种循环模式和手数倍增逻辑不变。

### 模式二：上一根K线范围模式

使用当前图表周期的上一根已完成K线：

```text
K线范围点数 = (上一根K线最高价 - 上一根K线最低价) / Point
```

用户设置两个边界：

- 最小K线范围：默认500点；
- 最大K线范围：默认1000点。

只有满足以下条件时，K线才有效：

```text
最小范围 <= K线范围 <= 最大范围
```

边界值包含在有效范围内：等于最小值或最大值都允许。

如果当前没有活动循环，且K线范围小于最小值或大于最大值，则该K线无效，不启动首单；EA等待下一根已完成K线重新检查。活动循环一旦确定了距离，后续不再因为K线范围变化而中断。

动态模式下，最终止损距离和止盈距离使用同一个有效K线范围。

K线范围模式的首单入场规则：

- 向上突破上一根K线最高价：正向开多，逆向开空；
- 向下突破上一根K线最低价：正向开空，逆向开多；
- `ordertype=正向开单` 自动使用模式一；
- `ordertype=逆向开单` 自动使用模式二；
- 没有突破时不启动订单组。

## 三、与六单循环的结合

原有循环模式保持不变：

| 模式 | 首单多 | 首单空 |
|---|---|---|
| 模式一 | BUY, SELL, SELL, BUY, SELL, SELL | SELL, BUY, BUY, SELL, BUY, BUY |
| 模式二 | BUY, SELL, BUY, SELL, BUY, BUY | SELL, BUY, SELL, BUY, SELL, SELL |
| 模式三 | BUY, SELL, BUY, BUY, SELL, BUY | SELL, BUY, SELL, SELL, BUY, SELL |

每次新订单建立后，仍然按照循环序号计算下一单方向，手数仍然是当前实际手数乘以用户设置的倍数。

在动态K线模式下，只有启动新循环时检查上一根已完成K线：

- K线有效：确定本轮止盈止损距离并启动循环；
- K线无效：暂不创建首单，下一根K线重新检查。

当前已经存在的持仓和已创建的预挂单，其止损和止盈不因后来K线范围变化而移动；距离在本轮建立时确定，后续预挂单和止损切换沿用该距离。

## 四、挂单和K线过滤的处理建议

下一单价格仍然取当前订单止损价，挂单类型仍按目标方向和价格位置自动选择：

- 反向多/空衔接使用Buy Stop或Sell Stop；
- 同向多/空衔接使用Buy Limit或Sell Limit。

推荐规则是：启动循环时检查K线范围并确定距离；后续挂单沿用当前持仓已确定的距离，并继续保留直到成交、止盈清理或被EA替换。这样不会因为下一根K线范围变化而撤掉或阻断已经属于当前循环的保护挂单。

如果用户希望严格禁止挂单在无效K线中成交，需要另行增加“无效K线撤销挂单”开关；当前版本不启用该行为，避免循环被后来K线范围中断。

## 五、参数设计

新增：

- `InpDistanceMode`：固定距离 / K线范围；默认固定距离；
- `ordertype`：正向开单 / 逆向开单；K线范围模式下默认正向开单；
- `InpCandleMinRangePoints`：最小K线范围，默认500点；
- `InpCandleMaxRangePoints`：最大K线范围，默认1000点。

保留：

- `InpStopLossDistancePoints`；
- `InpTakeProfitDistancePoints`；
- `InpFirstDirection`；
- `InpCycleMode`，支持模式一、模式二、模式三；
- `InpInitialLots`；
- `InpReverseMultiplier`；
- `InpMagicNumber`；
- `InpOrderComment`。

固定距离模式继续使用 `InpFirstDirection` 和 `InpCycleMode`；K线范围模式使用 `ordertype` 决定首单方向和循环模式。

参数校验：

- 所有距离必须大于0；
- 最大K线范围必须大于或等于最小K线范围；
- 如果动态模式取不到上一根已完成K线数据，则不创建新单并记录日志；
- 止损和止盈距离按品种Point计算并进行价格精度归一化。

## 七、验收标准

- 用户可以选择固定距离或K线范围模式；
- K线范围模式等待突破上一根K线高点或低点后才开首单；
- `ordertype` 正向自动绑定模式一，逆向自动绑定模式二；
- 启动新循环时，K线范围小于最小值或大于最大值时不创建首单；
- 循环运行中K线范围变化不影响后续预挂单、止损切换和加仓；
- K线范围等于边界值时允许创建新单；
- 动态模式的止盈和止损距离均使用有效K线范围；
- 三种六单循环模式继续正常工作；
- MT5和MT4行为一致；
- Python测试全部通过；
- MT5和MT4编译均为0错误、0警告。

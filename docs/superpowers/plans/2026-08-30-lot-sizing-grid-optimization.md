# 订单组累计手数与网格手数优化计划

## 目标

在 MT5 和 MT4 中统一订单组的手数规则，使网格加单、止损后的下一订单组首单和预挂单手数使用同一套可恢复状态。

## 规则

- 首个订单组首单使用 `InpInitialLots`，默认 `0.01`。
- 每个订单组的总手数等于首单手数加该组全部网格单手数。
- 订单组止损后，把该组总手数加入累计亏损手数；下一订单组首单使用累计值。
- 首个订单组的网格单手数等于首单手数。
- 后续订单组的网格单手数等于上一订单组网格单手数乘 `InpGridLotMultiplier`，默认 `2.0`。
- `InpGridCount` 表示止损区间的等分格数，默认 `2`；内部格点为第 `1` 到第 `N-1` 格，外层第 `N` 格仍然是止损和循环切换边界。
- 网格加单不推进六单循环索引；同一订单组的全部持仓共享外层止损。
- 每次网格成交后，止盈移动到最后一笔网格成交价加/减原止盈距离。
- 止盈结束本轮并清除累计亏损和网格状态。
- 固定距离和K线距离模式共用上述手数逻辑；K线距离只在新订单组创建时计算，订单组中途不重新计算。

## 实施内容

1. Python 策略模型增加订单组累计手数、网格手数和网格层级状态。
2. 增加首组网格、连续止损累计、网格翻倍、外层止损切换和止盈清零测试。
3. MT5 增加同方向持仓汇总、全部持仓统一止损止盈、网格成交和全局变量持久化。
4. MT4 同步实现订单汇总、网格成交、组级止盈移动和持久化。
5. 更新 README，明确参数与风险提示。

# EA 参数分组与中文提示整理设计

## 目标

让用户在 MT4/MT5 参数页中更容易找到需要设置的选项，并减少中文参数说明带来的歧义。此次仅整理显示分组和中文显示提示，不改变 EA 策略行为。

## 覆盖文件

- `NoMatterRiseFall_MT4.mq4`
- `NoMatterRiseFall_MT5.mq5`
- `NoMatterRiseFall_MT4_XAU_NetRR_v2_10.mq4`
- `NoMatterRiseFall_MT5_XAU_NetRR_v2_10.mq5`

## 设计

MT5 使用 MQL5 原生 `input group`，让参数按命名分组显示，并可折叠。MT4 不支持等价的原生分组语法，因此保留参数列表原顺序，通过每个参数行尾的中文显示说明标出分类和含义，不添加虚假的可编辑“分组参数”。两平台的分类名称和说明语义保持一致。

参数按用途组织为：

1. **首单与策略**：首单方向及其判断方式、循环模式、开单方式、K 线触发设置。
2. **入场距离与信号**：距离模式，以及固定距离、K 线高度、平均 K 线、布林带、ZigZag、时间箱体等各模式的专用参数。
3. **手数与风险**：首单手数、止损后的首单计算规则、反手上限、首单点差限制。
4. **网格与止盈止损**：网格数量/手数倍数、有利方向加单、动态止损、止盈移动方式及可视化开关。
5. **交易时段**：最多三个允许开首单的服务器时间段。
6. **订单识别**：订单识别编号和订单注释。
7. **净盈亏比与交易成本**（仅 XAU 净盈亏比版本）：净盈亏比开关、点差/滑点/佣金预算、止盈补偿、预计亏损比例和报价延迟限制。

具体分类归属以参数实际生效逻辑为准；MT4 与 MT5 对应策略参数尽量保持相同顺序和说明。版本独有参数留在最贴近其作用的分组中。

## 中文显示文案

中文显示说明优先回答“控制什么、单位是什么、特殊值代表什么”。使用简短明确的中文；需要时说明点数、倍数、服务器时间、关闭条件和 `0` 的含义。避免仅写“类型”“倍数”“高度”等无法单独辨认用途的词。对 0/1 开关用“0=关闭，1=开启”说明；枚举选项使用直白中文解释。

参数变量名、类型、默认值、内部映射宏和策略逻辑均保持不变。为让策略测试器按类别连续显示参数，允许并要求按上述类别重排声明；仓库 `.set` 文件以参数名映射取值，保留标识符即可维持映射。若某个参数行尾说明存在 MQL4 63 字符限制，文案应在该限制内。

## 验收标准

- 四个目标文件均有清晰一致的分类呈现；MT5 分组可折叠，MT4 不新增伪参数。
- 对应版本的参数中文说明准确说明用途和重要单位/特殊值，中文文案不再依赖内部英文变量名。
- 参数变量名、类型和默认值逐项保持原状；声明按类别连续排列。
- 运行相关自动化测试，并按 `AGENTS.md` 对标准 MT4/MT5 主文件运行 `scripts/compile-mql.ps1 -Target Both`；编译需零错误且生成文件已刷新，记录警告和输出路径。

## 明确不包含

- 策略公式、订单行为、验证规则或默认设置调整。
- 参数增删、改名、重排或改变 `.set` 文件含义。
- 重构 MT5 自定义图形界面或软件手册内容（除非后续实现发现直接依赖需要修改）。

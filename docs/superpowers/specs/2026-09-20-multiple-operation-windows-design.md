# Multiple Operation Windows Design

## Goal

将首单可用时间从单一时间窗口扩展为最多三个独立窗口：时段1、时段2、时段3。当前服务器时间命中任意启用窗口时允许首单；已有持仓、反向预挂单和网格管理行为保持不变。

## Compatibility and inputs

- 保留现有 `开始时间` / `结束时间` 作为时段1，默认仍为 `08:00` / `23:00`。
- 新增 `时段2开始时间` / `时段2结束时间` 和 `时段3开始时间` / `时段3结束时间`，默认均为 `00:00` / `00:00`。
- 不重命名现有输入，确保旧的 MT4/MT5 set 文件仍能加载原有时段1配置。
- 每个时段使用 `HH:MM`，支持跨午夜区间（例如 `22:00-02:00`）。
- 精确的 `00:00-00:00` 表示该时段未启用；非零的相同开始/结束时间表示全天有效，以保留原有全天语义。

## Runtime behavior

- MT4 和 MT5 都保存三个窗口的开始、结束分钟数。
- `IsInitialEntryAllowed` 逐个判断三个窗口，任意一个窗口命中即返回允许；三个窗口都关闭或当前时间均未命中时禁止新的首单。
- 时间判断仍只用于空仓且无挂单时的首单流程；已有交易组的止损、反手、网格和挂单管理不增加新的时间限制。
- GUI 配置校验要求六个时间值均为合法 `HH:MM`；应用配置时同步更新时间窗口运行时状态。

## MT5 GUI

- 风控与时段页面显示并可编辑六个时间字段，标签为“时段1开始/结束时间”“时段2开始/结束时间”“时段3开始/结束时间”。
- 时间下拉仍提供整点选项，文本编辑支持现有 `HH:MM` 校验。
- 概览页的“运行时间”显示三个窗口，关闭窗口显示为 `关闭`。
- 配置指纹包含全部六个时间字段，避免不同时间配置复用旧状态。

## Documentation and tests

- 更新 README 和 HTML 使用手册，说明三个窗口、跨午夜和关闭规则。
- 在 Python 策略模型中增加三个窗口参数及相同的命中规则，覆盖：任意窗口命中、窗口均未命中、跨午夜、关闭窗口和既有持仓在窗口外仍可管理。
- 增加 MT4/MT5 源码结构断言，确保三组输入、校验、GUI 字段和摘要都存在。

## Alternatives considered

1. 只增加一个逗号分隔的时间字符串：输入紧凑，但 MT4/MT5 参数界面和 MT5 GUI 都难以直观编辑，也会增加解析歧义。
2. 完全重命名旧输入为时段1字段：命名更整齐，但会破坏现有 set 文件；因此不采用。
3. 保留旧字段并新增两组字段：兼容性和可编辑性最好，采用此方案。

# 平均K线高度距离模式设计

## 目标

为 MT4 和 MT5 增加第三种止损距离来源：使用过去 N 根已完成K线的平均高度乘以止损倍数作为止损距离，并以止损距离乘以止盈倍数作为止盈距离。N 默认 20，止损倍数和止盈倍数默认 2.0。

## 已确认的行为

- `距离模式` 增加 `过去N根K线平均高度`，保留现有的 `固定距离` 和 `上一根K线高度`。
- 平均高度只计算已完成K线，使用索引 `1` 到 `N`，不包含当前正在形成的K线。
- 平均高度为每根K线的 `最高价 - 最低价` 的算术平均值，并转换为平台点数。
- 平均模式的止损距离为 `平均高度 × 止损倍数`，默认止损倍数为 `2.0`。
- 平均模式的止盈距离为 `止损距离 × 止盈倍数`，默认止盈倍数为 `2.0`。
- 平均模式使用固定距离模式的开单逻辑：首单按当前买价/卖价市价开单，不使用K线最高价/最低价预埋首单。
- 开单后的反手、网格、止盈和止损流程与其他距离模式相同。
- 平均模式在订单组建立时计算一次，并写入订单组的止损/止盈距离状态；后续 Tick 不重复改变已建立订单组的距离。
- 现有的 `K线最小高度` 和 `K线最大高度` 仅继续约束上一根K线高度模式，不用于平均模式中的单根K线筛选或最终平均值筛选。
- 当历史K线数量不足 N 根、数据无效或计算结果不大于零时，本次不建立订单组，等待后续数据满足条件。
- `K线开单模式=每根一次/每根多次` 的现有语义保留；平均模式不启用K线最高/最低点首单预埋逻辑。

## 代码结构

### 距离模式和参数

在 MT4、MT5 的 `DistanceMode` 中增加第三个枚举值，并增加以下输入/GUI配置字段：

- 平均K线根数，整数，默认 `20`，必须大于零。
- 止损倍数，浮点数，默认 `2.0`，必须大于零。
- 止盈倍数，浮点数，默认 `2.0`，必须大于零。

MT5 的 GUI 下拉框、配置序列化/反序列化、配置指纹和概要显示同步支持第三种距离模式及三个参数；MT4 通过输入参数提供相同配置。

### 平均距离计算

在两个平台各自的距离计算函数中增加平均K线高度分支，逻辑为：

```text
if bars < N + 1: fail
sum = 0
for shift = 1 .. N:
    high = High(shift)
    low = Low(shift)
    if high <= 0 or low <= 0 or high <= low: fail
    sum += (high - low) / point
average_range_points = round(sum / N)
stop_points = round(average_range_points * stop_multiplier)
take_profit_points = round(stop_points * take_profit_multiplier)
```

计算结果必须通过正数检查；订单组的后续逻辑继续使用已保存的 `g_group_stop_points`/`g_group_take_profit_points` 或对应并行组字段。

### 开单和后续管理

固定模式和平均模式共用市价首单分支。只有距离模式为上一根K线高度且开单模式为每根一次时，才进入K线最高/最低点双首单预埋分支。平均模式不改变反手挂单、网格挂单、止盈清理和OCO相关代码。

## 错误处理

- 参数校验拒绝 N、倍数为零或负数的配置。
- 历史K线不足或任一根K线数据异常时返回失败，不发送市价单或挂单。
- 计算出的止损或止盈点数无效时返回失败，并保留现有的下一Tick重试行为。
- 不改变固定模式和上一根K线高度模式的已有参数含义。

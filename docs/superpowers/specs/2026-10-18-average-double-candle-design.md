# 均值两倍 K 线独立 EA

用户已确认：信号 K 线长度达到或超过其之前 N 根均长的两倍才允许首单；止盈止损均取信号 K 线长度的同一百分比；保留公共循环、反手、网格、移动止盈、动态止损及风控。

使用图表周期刚收盘 K 线（shift 1）的 High-Low，比较 shift 2 至 N+1 的 High-Low 平均值。当前未收盘 K 线与信号 K 线都不计入均值。阳线买、阴线卖，十字星、历史不足及无效 OHLC 不开。N 默认 20，百分比默认 50%，均可调整。两倍阈值固定。每根信号只触发一次，包括首单拒单或组结束后，不逐 tick 重试。距离在首单信号时锁定，组内后续逻辑沿用公共核心。

新增 AverageDoubleCandle MT4/MT5 入口，固定 profile id 9，独立默认 Magic。仅呈现本策略的 N、距离百分比及公共参数，MT5 图表面板同样精简。新配置字段只在新 profile 编译，以保持原八模式配置指纹不变。原 Legacy 全模式入口不增加模式选择，只做兼容编译。

验证：边界（略小、等于、大于两倍）、涨跌方向、十字星、无效数据、N 边界、百分比点数、同根重复；输入/面板/隔离契约；全套 Python 回归；九模式双平台及 Legacy 编译；MT5 新模式单/双篮子生成 tick 回放，核对实际信号、保护距离、重复入场及运行错误。打包源文件和已刷新字节码，校验交付文件哈希。

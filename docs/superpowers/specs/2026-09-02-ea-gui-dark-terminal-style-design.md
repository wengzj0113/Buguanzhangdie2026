# 不管涨跌 EA 深色专业交易终端风格设计规格

**日期：** 2026-09-02
**范围：** MT5 图表内 GUI 的视觉风格、布局可读性和控件交互表现
**基础：** 沿用现有 EA 参数、草稿/应用模型、五个页面和交易操作语义，不改动交易策略算法

## 1. 目标

将现有图表 GUI 调整为“深色专业交易终端”风格，同时解决当前界面最影响使用的问题：

1. 参数和状态信息完整可见，不能因页面空间不足被裁切或覆盖。
2. 下拉选择、模式按钮和文本框具有明确的可操作反馈。
3. GUI 与图表交易标记分层，交易箭头、水平线不能绘制到 GUI 面板上方。
4. 界面紧凑但不牺牲字段可读性，用户可以快速完成参数设置和常用操作。

## 2. 已确定的视觉方向

### 2.1 色彩

- 主背景：近黑蓝色，降低对图表的干扰。
- 面板：深海军蓝，使用一层明显但克制的边框与图表区分。
- 输入区：比面板略深，输入框边框使用中等蓝灰色，保证可点击区域清晰。
- 选中态：使用高对比蓝色填充或边框，不依赖文字颜色单独表达状态。
- 正常运行/成功：绿色。
- 待应用/下一轮生效：黄色。
- 错误/危险操作：红色。
- 只读辅助信息：降低亮度，但仍保持可读对比度。

### 2.2 字体和密度

- 使用 MT5 可用的无衬线字体和中文兼容字体。
- 标题、区块标题、字段标签和字段值使用明确层级，避免全部使用同一字号。
- 字段标签使用较小的辅助字号；字段值和运行状态不能小到难以辨认。
- 每个字段都保留足够的左右内边距，长文本显示省略或换行，不覆盖相邻控件。

### 2.3 图表共存

- GUI 面板使用不透明背景，保证面板内文字和控件不被K线、箭头、交易线穿透。
- 显示完整 GUI 时临时隐藏图表的交易水平线和交易历史标记；隐藏/最小化/销毁 GUI 时恢复原来的图表设置。
- GUI 对象使用独立前缀和更高交互层级，不能被交易对象抢占点击。

## 3. 窗口结构

### 3.1 标题栏

左上角固定显示：

- `不管涨跌 EA`。
- 当前品种与周期，例如 `XAUUSD · M1`。
- 运行状态，例如 `运行中`、`已暂停` 或 `异常`。
- 最小化/恢复入口。

标题栏高度保持紧凑，但状态和按钮必须有独立点击区域。

### 3.2 主体布局

完整窗口由两部分组成：

- 左侧窄导航栏：总览、开仓、距离、网格、风控。
- 右侧内容区：当前页面的字段、只读状态和页面操作。

目标尺寸为当前图表常用分辨率下的紧凑悬浮窗口，默认宽度约 520px、高度约 580px。实现时以字段完整显示为优先，必要时使用内容区滚动或页面内分组，而不是压缩文字或让字段互相覆盖。

左侧导航的当前项使用蓝色选中背景；未选中项保持深色透明背景，鼠标悬停和键盘/点击焦点使用边框或亮度反馈。

### 3.3 内容区

每页采用“区块标题 + 字段网格”的结构：

- 区块标题显示当前分组名称和字段数量/状态摘要。
- 相关字段使用两列布局；长文本、备注和需要更宽输入区域的字段占满一行。
- 每个字段的标签与控件上下排列，避免标签和控件横向挤压。
- 底部操作区固定显示主要操作，不随字段重绘而漂移。

## 4. 页面内容

### 4.1 总览

总览页不再只显示“运行中”一行，至少显示：

- 运行状态。
- 当前方向。
- 当前订单组/循环状态。
- 反手次数与最大反手次数。
- 持仓数量与挂单数量。
- 首单手数与手数倍数。
- 距离模式、止损距离、止盈距离/模式。
- 网格数量与网格手数倍数。
- 交易时间段、Magic Number 和订单备注摘要。
- 草稿状态：无修改、存在未应用修改、应用成功或应用失败。

总览页的摘要是只读展示；参数修改仍在对应分组页面进行，避免用户误以为摘要字段可直接修改。

### 4.2 开仓

完整显示并可编辑：

- 首单方向。
- 循环模式。
- 订单类型。
- K线开单模式。
- 是否允许多个订单组并行。
- 首单手数。
- 首单手数倍数。

### 4.3 距离

完整显示并可编辑：

- 距离模式。
- 止损距离。
- 止盈距离。
- K线最小范围。
- K线最大范围。
- 止盈模式。

模式相关字段可以根据策略语义提示“当前模式下生效”，但不得因为简洁模式或页面切换而丢失已有值。

### 4.4 网格

显示并可编辑：

- 网格数量。
- 网格手数倍数。

同时显示当前网格成交状态、已使用层级和下一层级摘要；这些状态为只读。

### 4.5 风控

显示并可编辑：

- 最大反手次数。
- 开始时间。
- 结束时间。
- Magic Number。
- 订单备注。

危险操作提示使用黄色或红色辅助区域，避免与普通字段混淆。

## 5. 控件规范

### 5.1 选择控件

以下类型必须使用下拉选择，不使用自由文本框：

- 首单方向。
- 循环模式。
- 订单类型。
- K线开单模式。
- 距离模式。
- 止盈模式。
- 其他具有固定枚举值的参数。

MT5 图表对象没有浏览器原生下拉框时，使用 GUI 自己绘制的下拉菜单：点击字段打开选项列表，选中后立即更新草稿值；点击外部区域关闭菜单。选项层级必须高于其他 GUI 控件，不能被面板或字段遮挡。

### 5.2 数字和文本控件

- 手数、倍数、距离、数量、次数和 Magic Number 使用可编辑数字框。
- 开始时间、结束时间使用时间输入控件或受格式校验的文本框。
- 订单备注使用可编辑文本框。
- 文本框点击后必须获得焦点；输入期间不重建或覆盖对象，避免用户刚输入的内容被刷新掉。
- 输入结束后同步到草稿；非法值显示字段级错误，不静默转换为零。

### 5.3 状态和按钮

- 普通按钮使用深蓝灰背景，悬停/焦点时有明显边框反馈。
- `应用参数` 使用主蓝色。
- `暂停/恢复` 使用中性蓝灰色，并明确显示当前动作。
- `平仓并删除挂单` 使用红色，并保留二次确认。
- 按钮文字不能被截断，按钮之间保持足够间距。

## 6. 交互行为

1. 点击左侧导航必须切换页面，并保留当前草稿。
2. 点击枚举字段必须打开下拉菜单；点击选项必须切换值并更新控件显示。
3. 点击文本框必须可以输入、删除和替换内容；输入过程中页面不能自动重绘覆盖内容。
4. 所有编辑只修改 GUI 草稿，点击“应用参数”后才提交给策略层。
5. 未应用修改时，在标题栏或总览页显示黄色提示。
6. 应用成功显示成功状态；应用失败保留草稿并显示原因。
7. 交易中受保护的订单组参数不能被静默重写；需要下一轮生效时明确标记。
8. 最小化只改变 GUI 显示，不停止 EA，也不改变交易管理。
9. GUI 完整显示时，图表交易标记不能覆盖面板；恢复图表时必须还原用户原先的显示设置。

## 7. 验收标准

### 7.1 视觉验收

- 在 XAUUSD M1 图表上，完整窗口左上角显示，标题、导航、字段和操作区均不裁切。
- 深色面板与黑色图表有清晰边界，文字、输入框和选中状态易辨认。
- 当前页、运行状态、主操作和危险操作可以一眼区分。
- 交易箭头和水平线不会绘制到 GUI 控件上方。
- 窗口最小化后保留一条清晰的状态栏，恢复后布局不变。

### 7.2 交互验收

- 五个导航页均可点击切换。
- 每个枚举参数均能打开下拉菜单并切换选项。
- 每个数字/文本参数均能编辑，输入内容不会被 Tick 刷新覆盖。
- 修改后能看到未应用状态；点击应用后能看到成功/失败反馈。
- 平仓删挂单仍需要确认，取消确认不产生交易动作。

### 7.3 回归验收

- 现有策略单元测试保持通过。
- MT5 源码编译为 0 errors、0 warnings。
- 在真实 MT5 图表挂载后，通过截图和实际点击验证显示、下拉、文本编辑、应用参数和最小化/恢复。
- GUI 改版不增加额外开仓、平仓或挂单行为。

## 8. 非目标

本次风格改版不包含：

- 修改开仓、反手、网格、止损止盈算法。
- 增加独立桌面客户端或网页远程控制。
- 改变既有参数名称、参数含义或交易安全确认语义。
- 用装饰性图表、徽章或大面积卡片替代真实交易状态。

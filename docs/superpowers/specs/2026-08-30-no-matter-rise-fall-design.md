# 不管涨跌 EA 设计说明

## 目标

在MT5和MT4上实现同一套“不管涨跌”策略：固定距离模式在没有本策略持仓或挂单时按用户设置开首单；K线范围模式等待突破上一根已完成K线高低点后，按 `ordertype` 决定首单方向；首单成交后，在其外层止损价位放置下一订单组的反向挂单，并按订单组累计规则确定手数。订单组内允许按止损区间网格加单并移动止盈。

## 参数

- 首单方向：Buy 或 Sell，默认 Buy。
- 循环模式：模式一或模式二，默认模式一。
- 模式三：首单多时为 BUY, SELL, BUY, BUY, SELL, BUY；首单空时为 SELL, BUY, SELL, SELL, BUY, SELL。
- 止盈止损距离支持固定距离或上一根已完成K线范围；动态模式在首单启动时要求范围处于用户设置的最小值和最大值之间，距离确定后，当前循环不因后来K线范围变化而停止。
- 止盈移动方式支持网格移动止盈和线性移动止盈；默认使用网格移动止盈。
- K线范围模式的首单等待突破上一根已完成K线高点或低点；新增“开单方式”参数，正向开单自动使用模式一，逆向开单自动使用模式二。向上突破在正向模式开多、逆向模式开空；向下突破在正向模式开空、逆向模式开多。
- 首单手数：默认 0.01。
- 首单手数倍数：默认1.0；首次建立订单组时不使用该倍数，订单组止损后下一组首单才将累计止损手数乘此倍数。
- 网格数量：默认2，表示把止损区间等分为2格。
- 网格手数倍数：默认2.0，后续订单组网格手数为上一组的两倍。
- 止损距离：默认 500 点。
- 止盈距离：默认 500 点。
- 线性移动止盈以订单组成立价格为初始参考，只记录买单成立后的最低有效报价或卖单成立后的最高有效报价；止盈与该不利极值保持原止盈距离，价格反弹时不回退。
- 订单识别编号与订单注释：用于只管理本EA创建的订单。
- 开始时间与结束时间：按交易平台服务器时间限制首单开仓，格式为“时:分”，默认08:00至23:00；有效时间外不影响已有持仓和已有挂单，开始时间与结束时间相同时表示全天有效。

## 订单状态机

1. 无本EA持仓且无本EA挂单：固定模式直接按参数开首单；K线范围模式仅在上一根K线范围有效且价格突破其最高价或最低价时开首单，并设置其止损/止盈。
2. 有当前持仓但无下一单挂单：按六单循环索引取得下一方向，在当前订单组外层止损价位放置对应的 `Buy Stop`、`Buy Limit`、`Sell Stop` 或 `Sell Limit`。挂单手数等于当前订单组累计手数加上此前止损订单组累计手数。
3. 首单成交后，同时在外层止损位置挂下一订单组的循环单，并在第一内部网格价位挂同方向网格单。每个内部网格只保留一张预挂单；该网格单成交后，才在下一内部网格价位挂下一张。网格订单与当前订单同方向，且不推进六单循环索引。网格移动止盈模式下，网格成交后当前订单组全部持仓共享外层止损，止盈移动到最后网格成交价加/减原止盈距离；线性移动止盈模式下，价格每次创出不利方向新极值时，当前订单组全部持仓的止盈按相同点数移动，外层止损不变。
4. 价格到达外层止损价位：若反向预挂单已经成交，EA只处理该成交订单，不再额外市价开单；若反向预挂单尚未成交，EA先删除当前订单组的反向预挂单和网格挂单，确认删除完成后再平当前订单组，并以累计亏损订单组手数市价开下一订单组。删除失败时保留当前状态，下一次Tick重试。
5. 当前订单组达到移动后的止盈：平掉该组全部持仓并删除剩余反向挂单，清除累计亏损和网格状态；下一次空仓时重新开始首单。

止损和止盈距离均按交易品种的 `Point` 计算，价格和手数按经纪商最小跳动与交易量步长归一化。

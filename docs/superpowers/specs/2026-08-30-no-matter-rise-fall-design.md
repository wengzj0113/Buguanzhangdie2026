# 不管涨跌 EA 设计说明

## 目标

在MT5和MT4上实现同一套“不管涨跌”策略：没有本策略持仓或挂单时，按用户设置开首单；首单成交后，在其止损价位放置反向止损挂单；挂单成交后继续以当前单的止损价位放置下一张反向单，手数按配置倍数递增。

## 参数

- 首单方向：Buy 或 Sell，默认 Buy。
- 首单手数：默认 0.01。
- 反向手数倍数：默认 2.0。
- 止损距离：默认 500 点。
- 止盈距离：默认 500 点。
- Magic Number 与订单注释：用于只管理本EA创建的订单。

## 订单状态机

1. 无本EA持仓且无本EA挂单：开首单，并设置其止损/止盈。
2. 有当前持仓但无反向挂单：在当前持仓止损价位放置反向 `Sell Stop` 或 `Buy Stop`，手数为当前手数乘以倍数。
3. 价格到达止损价位：由服务器挂单触发；若行情更新顺序导致挂单未及时成交，EA先平当前单，再以反向市价单补成交，并为新单放置下一张反向挂单。
4. 当前单达到止盈：平仓并删除剩余反向挂单，本轮结束；下一次空仓时重新开始首单。

止损和止盈距离均按交易品种的 `Point` 计算，价格和手数按经纪商最小跳动与交易量步长归一化。

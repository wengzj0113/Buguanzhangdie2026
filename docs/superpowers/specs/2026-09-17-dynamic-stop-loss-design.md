# 动态止损设计方案

## 目标

新增中文参数“动态止损”，让价格向有利方向移动并成交网格订单后，订单组止损按相同的网格距离向有利方向移动；默认关闭时保持现有固定止损逻辑。

## 参数与界面

- MT4、MT5 增加 `动态止损` 输入参数，类型为整数，默认值为 `0`。
- `动态止损=0` 表示关闭动态止损，止损继续锚定订单组首单价格。
- `动态止损=1` 表示开启动态止损。
- 参数在 MT4/MT5 的中文设置页面“网格”区域显示为“动态止损”，选项为“关闭/开启”。
- GUI 配置、持久化指纹、参数校验和运行时配置必须包含该字段。

## 止损计算

订单组的基础止损仍按原有逻辑计算：

- 买单：`锚定价 - 止损距离`。
- 卖单：`锚定价 + 止损距离`。

开启动态止损后，使用已成交的有利方向网格最高层级计算移动步数：

`网格间距 = 止损距离 / 网格数量`

- 买单：`动态止损 = 基础止损 + 最高有利网格层级 × 网格间距`。
- 卖单：`动态止损 = 基础止损 - 最高有利网格层级 × 网格间距`。

使用最高层级而不是成交次数，避免价格跳过某层级或多个挂单同一时刻成交时止损移动过度。动态止损只会向有利方向移动，不会因不利方向网格成交而反向放宽。

当 `动态止损=0`、网格数量不足或没有有利方向网格成交时，计算结果必须与当前固定止损一致。

## 运行流程

1. 有利方向网格成交后，现有网格成交处理更新成交掩码和最后成交价。
2. 止损计算函数读取有利网格最高成交层级，得到新的止损价。
3. `SetGroupStops`/`MultiSetStops` 将新止损写入当前订单组全部同方向持仓。
4. 持仓保护校验失败时，继续沿用现有“暂停后续订单并重试”的安全策略。
5. 反向挂单使用重新计算后的动态止损价作为触发价；止盈移动逻辑保持不变。

## 测试范围

- 默认关闭：有利和不利网格成交后止损均不移动。
- 买单开启：有利网格第 1、2 层成交时止损分别移动 1、2 个网格间距；不利网格成交不改变止损。
- 卖单开启：有利网格成交后止损向下移动相应网格间距。
- MT4/MT5 源码均包含参数、中文 GUI、校验、单组和多组计算路径。
- 现有止损后反手、最大手数、网格数量和止盈测试全部保持通过。

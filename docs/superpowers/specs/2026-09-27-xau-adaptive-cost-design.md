# XAUUSD 自适应成本参数设计（v2.11）

## 目标

在独立的 MT4/MT5 v2.11 文件中，将当前确认的成本预算设为可用起始默认值，并增加交易环境识别与成交成本学习。原 v2.10 与原版文件保持不变。成本模式继续默认关闭，默认值只在用户启用成本模式后生效。

自动适配用于将预算换算到当前品种/经纪商规格，并从已观察到的成交费用与滑点中提高成本预留。它不承诺或保证实际盈亏比，也不因点差变大而放宽入场门槛。

## 默认参数

| 参数 | v2.11 默认值 | 说明 |
| --- | ---: | --- |
| 启用 XAU 净盈亏比成本模式 | `false` | 保留默认运行行为；启用前需确认 XAUUSD/对冲账户与预算 |
| 目标净盈亏比 | `0` | 跟随策略原止盈距离/止损距离 |
| 最大开仓点差 | `30` 参考点 | 以 XAU 报价 `$0.01/盎司` 为一个参考点，运行时换算成本机 Point |
| 最大点差占止损比例 | `0.10` | 绝对点差和相对止损距离的上限同时生效 |
| 最大开仓滑点预算 | `5` 参考点 | 作为预算/过滤门槛，不是成交价保证 |
| 预计平仓滑点预算 | `10` 参考点 | 计入止损损失估算 |
| 每手往返佣金及费用预算 | `7` 账户货币/手 | 保守估算底值，自动学习不得将其调低 |
| 最大止盈补偿 | `100` 参考点、`0.20` 原止盈比例 | 两个上限同时生效 |
| 单轮风险上限 | `0.02` 权益 | 自动环境识别不能调高该比例 |
| 全部并行轮次风险上限 | `0.05` 权益 | 自动环境识别不能调高该比例 |
| 最长报价延迟 | `5000` 毫秒 | 超时禁止新增风险 |

以上参数是依据已有生成 Tick 测试配置采用的**起始值**，没有目标经纪商实盘调优含义。成本模式仍关闭，避免未知经纪商佣金/点差下直接启用。

## 自动环境识别与单位换算

MT4/MT5 启动及重新连接后读取品种基础币种/报价币种、Digits、Point、tick size、tick value、合约大小、最小/最大手数、手数步长、止损和冻结距离；同时读取账户币种、保证金模式、服务器与账号标识。黄金识别使用品种属性 `base=XAU`、`profit=USD`，以兼容 `XAUUSD.a` 等后缀；无法确认黄金规格时成本模式拒绝新开仓。

默认“参考点”换算为实际价格距离，再除以经纪商 Point 生成原生点数，避免两位/三位报价把 `$0.30` 点差预算解释成不同金额。盈亏与账户币种换算仍使用平台合约信息/平台盈亏计算函数。最小手数、手数步长和服务器 stops/freeze level 仅用于订单标准化与合法性检查，不能被自动调宽为风险额度。

## 成交成本学习

每个服务器、账号、账户币种、品种分别维护成本档案。运行时按分钟抽样报价点差；对入场/止损成交分开记录请求触发价与实际成交价的逆向差额；对已归属的成交历史记录 commission、fee、swap 和利润。成本样本按账户历史 deal/订单组关联，重复事件去重并可重启恢复。

样本不足时沿用上述预算底值。点差至少累积 30 个有效的分钟样本后，按最近 256 个分钟样本的第 95 百分位估算；滑点与可归属往返费用至少有 20 个完整样本后，按最近 100 个完整样本的第 95 百分位估算。实际费用按关联 position 的总费用除以其总成交手数计算。各项未来费用采用 `effective_budget=max(configured_floor, learned_p95)`；费用无法归属、历史不完整或经纪商另行记账时不把费用假定为零，保留预算并输出诊断。统计值只允许提高费用/滑点预留，绝不自动降低底值。

点差入场限制为以下条件中更严格的一项：默认绝对上限、止损占比上限、学习档案中的历史第 95 百分位上限。历史统计只能收紧上限；不能把绝对上限调大。若采样不足，不使用历史分位收紧项。

风险比例、网格倍数、止损距离、交易方向、最大手数与目标盈亏比不由学习器自动调整。当前成本超过预算或参数无法验证时，拒绝新增风险并保留已在服务器的止损/止盈。

## 配置与状态展示

自动适配在成本模式启用时运行，无需增加第二个“自动开关”。EA 状态区域显示识别出的品种属性、账户/保证金类型、换算后的有效阈值、历史样本数、学习到的费用/滑点估算、当前点差及冻结/拒绝原因。输入预算作为用户最低预算；动态学习结果不覆盖输入值。

MT5 成本模式继续仅支持对冲账户。MT4 和 MT5 使用相同的参考价格单位及估算规则，并分别通过平台属性接口取得合约细节。旧模式（成本模式关闭）行为保持 v2.10 回归结果。

## 错误处理和风险边界

- XAU 属性、tick size/value、Point、成交历史映射、账户类型任一关键值不可验证时，成本模式阻止新开仓并记录原因。
- 经纪商佣金单独入账且无法匹配 position/order 时，保留每手费用预算、报告账本差额；不能自动用余额变化推断为 EA 佣金。
- 实际成交价越过滑点预算时，先回读服务器 SL/TP，冻结该轮新增风险并记录实际偏差。
- 网络断开、EA 停止或跳空仍可能使实际滑点、平仓成本和最终盈亏比超过估值；自动适配不构成执行保证。
- v2.11 参数需由用户在 EA 输入页启用成本模式；不得自动修改实盘账户或启动交易。

## 验收标准

1. 新建 MT4/MT5 v2.11 源码及编译文件；原版和 v2.10 哈希不变。
2. 截图所示默认值符合表格，成本模式为 `false`。
3. 点值换算测试覆盖不同 Digits、Point、tick size；XAU 后缀品种依元数据识别，非 XAU 与元数据缺失时 fail closed。
4. 成本学习测试验证低样本回退、P95 提高预算、费用去重/延迟到账/重启恢复、不能降低底值或放宽点差硬上限。
5. MT4/MT5 编译零错误、零新增警告；成本模式关闭回归旧行为。
6. 用合成/策略测试器数据验证门槛，不把生成 Tick 结果称为经纪商调优或实盘性能证明。取得目标经纪商真实 Tick、费用账单和滑点样本后，再另行做实盘参数校准。

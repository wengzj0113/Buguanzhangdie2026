# 止损首单固定手数类型设计

## 目标

为“不管涨跌”EA 的“止损首单类型”增加类型 3：固定手数。用户可通过新增参数指定止损后下一订单组首单手数，默认值为 0.01。

## 行为

- 首次启动或全新周期重启时，仍使用现有“首单手数”；类型 3 不改变这一路径。
- 当止损首单类型为 1 或 2 时，维持现有计算方式不变。
- 当止损首单类型为 3 时，所有止损切换路径的下一组首单直接采用新增的“止损首单固定手数”，包括反向预挂单提前成交的路径；该手数不再乘“首单手数倍数”或“首单类型2倍数”。
- 新固定手数作为下一组首单手数进入现有订单组状态，因此该组网格手数按当前网格初始化/递推规则处理，不额外改变网格加仓公式。
- 类型 3 在 MT4、MT5 的单组和多组订单管理中行为一致。

## 参数与验证

- 新增参数“止损首单固定手数”，默认 0.01，需为有效正数且符合品种交易量最小值、最大值和步长约束。
- “止损首单类型”允许值从 1、2 扩展为 1、2、3。
- MT5 图形参数配置、配置复制/校验/持久化及显示应包含新参数；MT4 使用对应的 EA 输入参数和现有配置路径。
- 自动化逻辑测试覆盖类型 3 的固定量、类型 1/2 回归、反向切换/止损后计算路径以及两份专家源码的参数声明。
- 按项目要求运行相关自动化测试，并编译 MT4 与 MT5 两份 canonical 源码。

## 不在范围内

- 不改变首次首单手数、类型 1/2 计算、订单组网格手数递推或新周期重启规则。
- 不改变止损、反手次数、挂单方向或订单执行时序。

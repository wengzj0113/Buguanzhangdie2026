# 有利方向网格加单设计

## 目标

新增 `FavorableGridEnable` 参数，让用户选择价格向持仓有利方向移动时是否也进行网格加单，同时保持现有不利方向网格加单逻辑不变。

## 参数与用户界面

- 内部逻辑名：`FavorableGridEnable`；原生输入项使用中文变量名 `有利方向加单`
- 默认值：`0`
- `0`：价格向有利方向移动时不加单。
- `1`：价格向有利方向移动时加单。
- MT4/MT5 原生参数设置页面、MT5 自定义参数页面、概览页面和相关提示全部显示中文“有利方向加单”，不向用户展示英文参数名。

## 行为规则

当前订单组首单成交后，仍按原逻辑在不利方向布置网格单；“网格数量”仍决定不利方向可用的网格层数。开启参数后，同一订单组还在有利方向布置同样数量的网格层，网格间距使用该组锁定的止损距离除以网格数量，网格单手数使用该组既有网格手数。

买单的有利方向是价格上涨，卖单的有利方向是价格下跌；有利方向网格使用与持仓同方向的限价单。不利方向的网格单类型和价格规则保持现有实现。内外层止损、订单组切换、六单循环和首单手数计算不因该参数改变。

## 状态与兼容性

每个订单组分别记录有利方向网格的已成交层级和挂单状态，单组与 K 线多组模式都适用。关闭参数时不创建有利方向网格，也不读取或影响现有不利方向状态。重启恢复和重复挂单清理必须识别新增方向的网格订单，旧状态没有新字段时按空状态兼容。

## 测试标准

- 参数为 `0` 时，买单上涨、卖单下跌不产生有利方向网格单。
- 参数为 `1` 时，买单上涨、卖单下跌分别按用户设置的网格数量产生同向网格单。
- 原有买单下跌、卖单上涨网格行为继续通过。
- 单组和多组的网格状态互不干扰。
- MT4、MT5 源码和已编译文件均包含该参数；MT5 可在中文设置页编辑并在概览页查看。

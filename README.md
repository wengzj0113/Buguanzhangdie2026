# 不管涨跌 EA

本目录包含同一策略的MT5与MT4版本：

- `NoMatterRiseFall_MT5.mq5` / `NoMatterRiseFall_MT5.ex5`
- `NoMatterRiseFall_MT4.mq4` / `NoMatterRiseFall_MT4.ex4`

策略在当前品种没有本EA订单时按 `InpFirstDirection` 开首单；随后按 `InpCycleMode` 选择的六单序列，在当前单止损价位准备下一单。模式一为“多空空多空空”（首单空时方向取反），模式二为“多空多空多多”（首单空时方向取反），模式三为“多空多多空多”（首单空时方向取反）。同向衔接使用Limit挂单，反向衔接使用Stop挂单，手数为当前手数乘 `InpReverseMultiplier`。止盈后删除剩余挂单并结束本轮。

止盈止损距离支持两种模式：固定距离模式，或上一根已完成K线范围模式。选择K线范围模式时，EA等待价格突破上一根已完成K线的最高价或最低价后才开首单；新增参数 `ordertype` 选择正向或逆向开单，正向自动使用模式一，逆向自动使用模式二。动态距离必须处于最小值和最大值之间（默认500到1000点），距离一旦确定，当前订单组后续的预挂单、止损切换、方向和加仓不再因后来K线范围变化而中断。边界值包含在有效范围内。固定距离模式继续使用 `InpFirstDirection` 和 `InpCycleMode`。默认参数：模式一、首单多、固定距离、正向开单、首单0.01手、倍数2.0、止损500点、止盈500点。参数均可在EA输入项中调整。循环索引和当前订单组距离会保存到终端全局变量，EA重启后会继续当前循环。

这是递增手数策略，连续止损会快速增加风险，请先在模拟盘和策略测试器中验证经纪商的最小手数、手数上限、止损距离和保证金条件。

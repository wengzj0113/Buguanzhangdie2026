# 不管涨跌 EA

本目录包含同一策略的MT5与MT4版本：

- `NoMatterRiseFall_MT5.mq5` / `NoMatterRiseFall_MT5.ex5`
- `NoMatterRiseFall_MT4.mq4` / `NoMatterRiseFall_MT4.ex4`

策略在当前品种没有本EA订单时按设置开首单；随后按六单循环序列，在当前订单组的外层止损价位准备下一订单组。模式一为“多空空多空空”（首单空时方向取反），模式二为“多空多空多多”（首单空时方向取反），模式三为“多空多多空多”（首单空时方向取反）。同向衔接使用限价预挂单，反向衔接使用突破预挂单。

止盈止损距离支持两种模式：固定距离模式，或上一根已完成K线范围模式。选择K线范围模式时，EA等待价格突破上一根已完成K线的最高价或最低价后才开首单；参数“开单方式”选择正向或逆向开单，正向自动使用模式一，逆向自动使用模式二。动态距离必须处于最小值和最大值之间（默认500到1000点），距离一旦确定，当前订单组后续的预挂单、止损切换、方向和加仓不再因后来K线范围变化而中断。边界值包含在有效范围内。固定距离模式继续使用“首单方向”和“循环模式”。参数“止盈移动模式”选择网格移动止盈或线性移动止盈。默认使用网格移动止盈。

网格和订单组手数规则如下：首次建立订单组时直接使用“首单手数”，不乘“首单手数倍数”；订单组止损后，下一订单组首单等于此前所有止损订单组总手数之和，再乘“首单手数倍数”（默认1.0）。当前订单组的每个网格单使用固定的该组网格手数，下一组网格手数为上一组网格手数乘“网格手数倍数”（默认2.0）。首组网格手数默认等于首单手数。“网格数量”表示把止损区间分成的格数，默认2，因此内部网格价位为首单到外层止损之间的等分点，外层止损仍负责订单组切换。

“最大反手次数”限制止损后切换到下一订单组的次数，默认5次；循环中每次止损切换都计数（包括同方向衔接）。达到上限后不再创建下一反手订单组，EA会清理本EA当前品种和订单识别编号下的全部持仓与挂单，清理完成后从下一次Tick重新开始首单流程。设置为0表示首组止损后直接清理并重新开始。

订单组止损止盈距离在组内锁定。首单成交后先预挂第一张同向网格单；每张网格单成交后才预挂下一格，不用市价追单。当前组所有持仓的止损保持在外层止损。网格移动止盈模式下，止盈只有在网格单成交后才移动到最后一笔网格成交价加/减原止盈距离；线性移动止盈模式下，只要价格向当前订单组的不利方向移动，止盈就按相同点数向不利方向移动，价格反弹时止盈不回退。网格加单不会推进六单循环索引。止盈后删除剩余挂单、清空亏损累计并结束本轮。

参数说明：“首单方向”为首单做多或做空；“循环模式”为固定距离模式下的循环方式；“距离模式”为止盈止损距离来源；“开单方式”为K线范围模式下的正向或逆向开单方式；“止盈移动模式”为网格或线性移动止盈方式；“首单手数”为首轮订单组的原始首单交易量；“首单手数倍数”为订单组止损后下一组首单交易量的倍数；“最大反手次数”为止损后允许切换订单组的最大次数；“网格数量”为止损区间等分格数；“网格手数倍数”为下一订单组网格手数倍数；“固定止损距离”和“固定止盈距离”为固定模式下的距离点数；“K线最小高度”和“K线最大高度”为K线范围限制；“订单识别编号”为识别本EA订单的编号；“订单注释”为发送到交易平台的订单说明。

“开始时间”和“结束时间”用于限制首单开仓时间，格式为“时:分”，按交易平台服务器时间判断，默认每天08:00至23:00有效。有效时间之外只禁止空仓且无挂单时开首单；已有持仓、反向预挂单和网格预挂单均不受影响。开始时间和结束时间相同表示全天允许。

如果市价单因为资金不足被拒绝（MT5错误码10019，MT4对应资金不足错误），EA会删除本EA当前品种和订单识别编号下的全部反向预挂单、网格挂单，并关闭全部多空持仓；清仓未完成前禁止开新单。清仓完成的当前Tick直接结束，下一次Tick才重新执行首单流程。重新开始时累计亏损手数、循环索引、网格状态和旧订单组距离全部清空；固定距离模式重新检查有效操作时间，K线高度模式重新检查当时上一根K线的高度和突破条件，首单使用基础“首单手数”。

这是递增手数策略，连续止损会快速增加风险，请先在模拟盘和策略测试器中验证经纪商的最小手数、手数上限、止损距离、保证金条件，以及MT5账户的净持仓/对冲模式差异。

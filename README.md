# 不管涨跌 EA

本目录包含同一策略的MT5与MT4版本：

- `NoMatterRiseFall_MT5.mq5` / `NoMatterRiseFall_MT5.ex5`
- `NoMatterRiseFall_MT4.mq4` / `NoMatterRiseFall_MT4.ex4`

策略在当前品种没有本EA订单时按设置开首单；随后按六单循环序列，在当前订单组的外层止损价位准备下一订单组。模式一为“多空空多空空”（首单空时方向取反），模式二为“多空多空多多”（首单空时方向取反），模式三为“多空多多空多”（首单空时方向取反）。同向衔接使用限价预挂单，反向衔接使用突破预挂单。

止盈止损距离支持两种模式：固定距离模式，或上一根已完成K线范围模式。选择K线范围模式且“K线开单模式”为“每根一次”时，EA会在上一根已完成K线的最高价和最低价同时预埋首单：开单方式为正向时最高点预埋多单、最低点预埋空单；逆向时最高点预埋空单、最低点预埋多单。一张首单成交后会取消另一张未成交首单，再进入当前订单组的正常管理。选择“每根多次”时仍等待价格突破上一根已完成K线的最高价或最低价后市价开首单。参数“开单方式”只决定K线首单的方向映射，循环方向仍完全使用用户选择的“循环模式”。动态距离必须处于最小值和最大值之间（默认500到1000点），距离一旦确定，当前订单组后续的预挂单、止损切换、方向和加仓不再因后来K线范围变化而中断。边界值包含在有效范围内。固定距离模式继续使用“首单方向”和“循环模式”。参数“止盈移动模式”选择网格移动止盈或线性移动止盈。默认使用网格移动止盈。

网格和订单组手数规则如下：首次建立订单组时直接使用“首单手数”，不乘“首单手数倍数”；订单组止损后，下一订单组首单由“止损首单类型”决定。默认“止损首单类型=2”，此时下一组首单等于上一止损订单组首单手数乘“首单类型2倍数”（默认2.0），不包含该组后续网格加仓手数；设置“止损首单类型=1”时保持原有逻辑，下一组首单等于此前所有止损订单组总手数之和，再乘“首单手数倍数”（默认1.0）。当前订单组的每个网格单使用固定的该组网格手数，下一组网格手数为上一组网格手数乘“网格手数倍数”（默认2.0）。首组网格手数默认等于首单手数。“网格数量”表示把止损区间分成的格数，默认2，因此内部网格价位为首单到外层止损之间的等分点，外层止损仍负责订单组切换。

“有利方向加单”控制价格向持仓有利方向移动时是否也挂同方向网格单：0为关闭（默认），只在不利方向加单；1为开启，买单上涨或卖单下跌时也按与不利方向相同的“网格数量”和当前组网格手数加单。两侧网格共用当前订单组的止损和止盈管理，不推进六单循环索引。

“最大反手次数”限制止损后切换到下一订单组的次数，默认5次；循环中每次止损切换都计数（包括同方向衔接）。达到上限后不再创建下一反手订单组，EA会清理本EA当前品种和订单识别编号下的全部持仓与挂单，清理完成后从下一次Tick重新开始首单流程。设置为0表示首组止损后直接清理并重新开始。

“K线开单模式”（内部参数名 `Korder_type`）只在距离模式选择“K线高度”时生效：0表示同一根当前K线 k0 只允许创建一次双向首单预埋，首单一侧成交后取消另一侧；1表示同一根 k0 可以按突破条件重复市价开首单。模式0默认开启。模式0在止盈完成后会记住当前k0，当前K线内不会立即按前一根K线重新挂单；检测到新K线时，先删除上一订单组残留的未成交挂单，再检查刚完成的k1高度，只有k1有效才在其最高价和最低价重新挂双向首单，k1无效则等待下一根K线。同一根K线内不会重复创建另一组。模式1保持原有突破后市价开首单逻辑。

“K线多组”只在距离模式选择“K线高度”时生效：0表示保持单订单组，已有持仓或挂单时不建立新组；1表示只要上一根K线高度有效且当前k0突破上一根K线极值，就允许建立新的独立订单组。每个订单组分别锁定自己的K线止盈止损距离、循环、反向预挂单、网格、移动止盈、手数和最大反手次数。“K线开单模式”为每根一次时仍限制同一根k0只触发一次，为每根重复时允许同一根k0重复建立订单组。固定距离模式忽略该参数并保持原逻辑。

订单组切换采用“已成交不重复、未成交先删除再市价反手”规则：如果止损位置的反向预挂单已经成交，EA只处理该成交订单，不再额外执行市价切换；如果止损发生时反向预挂单仍未成交，EA先删除当前订单组的反向预挂单和网格挂单，确认没有残留挂单后立即市价开出下一方向。若删除失败则保留当前状态，下一次Tick重试，避免旧挂单随后成交造成重复开单。

市价反手前会持久化“准备切换”阶段和切换标识，成交确认后保存“切换完成”。若终端恰好在两者之间重启，EA先扫描服务器上是否已经存在预期方向和手数的结果仓位：存在则接管，不存在才恢复发送一次，避免重启窗口重复反手。

同一服务器、账户、品种和订单识别编号在同一台电脑上只允许一个EA实例执行交易；策略测试器的锁名额外包含测试图表标识，避免并行回测互相阻塞。单订单组运行时，反向挂单和网格挂单分别按当前订单组预期的方向、价格和手数核对：只保留票据最小的一张正确挂单，错误或重复挂单删除完成后才允许补挂。若已出现多张基础仓位或同一网格价位的重复仓位，EA会撤销该作用域的挂单并暂停新开仓，不自动平掉异常持仓；应先人工核对并处理重复仓位。不同电脑之间不能共享本地实例锁，因此跨电脑运行时仍必须使用不同的订单识别编号。

若重启后检测到无持仓但仍有残留挂单，EA会先按已保存订单组状态核对并清理错误或重复挂单；若订单组状态已经无法恢复，则删除该作用域全部残留挂单并清空旧状态，只允许从下一次Tick重新进入首单流程。

订单组止损止盈距离在组内锁定。首单成交后先预挂第一张同向网格单；每张网格单成交后才预挂下一格，不用市价追单。当前组所有持仓的止损保持在外层止损。网格移动止盈模式下，止盈只有在网格单成交后才移动到最后一笔网格成交价加/减原止盈距离；线性移动止盈模式下，只要价格向当前订单组的不利方向移动，止盈就按相同点数向不利方向移动，价格反弹时止盈不回退。网格加单不会推进六单循环索引。止盈后删除剩余挂单、清空亏损累计并结束本轮。

参数说明：“首单方向”为固定距离模式首单做多或做空；“循环模式”为所有单组模式均使用的循环方式；“距离模式”为止盈止损距离来源；“开单方式”为K线范围模式下的正向或逆向开单方式；“K线开单模式”为每根K线一次创建双向首单预埋或允许重复市价首单；“K线多组”为K线高度模式是否允许多个订单组并行；“止盈移动模式”为网格或线性移动止盈方式；“首单手数”为首轮订单组的原始首单交易量；“止损首单类型”为止损后首单计算方式，1为累计订单组总手数的原有逻辑，2为上一止损组首单手数；“首单类型2倍数”为计算方式2使用的上一组首单手数倍数；“有利方向加单”为是否在有利方向按相同网格数量加单；“首单手数倍数”为计算方式1下订单组止损后下一组首单交易量的倍数；“最大反手次数”为止损后允许切换订单组的最大次数；“网格数量”为止损区间等分格数；“网格手数倍数”为下一订单组网格手数倍数；“固定止损距离”和“固定止盈距离”为固定模式下的距离点数；“K线最小高度”和“K线最大高度”为K线范围限制；“订单识别编号”为识别本EA订单的编号；“订单注释”为发送到交易平台的订单说明。

“开始时间”和“结束时间”用于限制首单开仓时间，格式为“时:分”，按交易平台服务器时间判断，默认每天08:00至23:00有效。有效时间之外只禁止空仓且无挂单时开首单；已有持仓、反向预挂单和网格预挂单均不受影响。开始时间和结束时间相同表示全天允许。

如果市价单因为资金不足被拒绝（MT5错误码10019，MT4对应资金不足错误），EA会删除本EA当前品种和订单识别编号下的全部反向预挂单、网格挂单，并关闭全部多空持仓；清仓未完成前禁止开新单。清仓完成的当前Tick直接结束，下一次Tick才重新执行首单流程。重新开始时累计亏损手数、循环索引、网格状态和旧订单组距离全部清空；固定距离模式重新检查有效操作时间，K线高度模式重新检查当时上一根K线的高度和突破条件，首单使用基础“首单手数”。

这是递增手数策略，连续止损会快速增加风险，请先在模拟盘和策略测试器中验证经纪商的最小手数、手数上限、止损距离、保证金条件，以及MT5账户的净持仓/对冲模式差异。

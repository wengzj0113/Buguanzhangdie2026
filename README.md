# 不管涨跌 EA

本目录包含同一策略的MT5与MT4版本：

- `NoMatterRiseFall_MT5.mq5` / `NoMatterRiseFall_MT5.ex5`
- `NoMatterRiseFall_MT4.mq4` / `NoMatterRiseFall_MT4.ex4`

中文使用手册：[EA软件使用手册.html](EA软件使用手册.html)

修改 MT4/MT5 主策略源码后，先运行自动化测试，再执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\compile-mql.ps1 -Target Both`。脚本会自动发现 MetaEditor，编译生成同目录的 `.ex4` / `.ex5`，并在结果中报告错误、警告和文件路径。若自动发现失败，可使用 `-MetaEditor4Path` / `-MetaEditor5Path` 指定编译器，或设置 `METAEDITOR_MT4_PATH` / `METAEDITOR_MT5_PATH` 环境变量。

“最大首单点差”按 points 设定，默认 0 表示关闭限制。大于 0 时，当前点差（按整数 points 向上取整）超过阈值便暂停新首单；已有的 K 线双向首单挂单也会在超限时撤销，点差恢复且当前 K 线信号仍有效时重新挂出。该限制不作用于反手切组、网格加单或已有订单组管理。

布林带区间模式只在当前报价触及上轨或下轨时开新首单；方向共用“开单方式”：正向时触及上轨做多、下轨做空；逆向时触及上轨做空、下轨做多。带内不入场。此方向也用于K线高度模式，不影响布林带中轨首单方向判断。止损距离为当前布林带上下轨宽度乘“布林带止损百分比”（默认25%，即原有四分之一带宽）并四舍五入为止损距离；止盈距离为最终止损距离乘“布林带盈亏比”（默认1.0）。再检查“布林带最小止损距离”和“布林带最大止损距离”（默认200和1000点，含边界）。距离不在范围内时不创建首单，下一次行情重新判断；不将距离截断到边界。已有订单组继续使用建立时锁定的距离，止损后的订单组切换和网格管理不因随后布林带宽度变化而中断。K线最小/最大高度参数不影响布林带模式。

ZigZag 波段模式使用当前品种、图表周期的标准 ZigZag。Depth、Deviation、Backstep 默认 12、5、3；为避开指标最近三个会回算的极值，EA 使用第 4、第 5 个相邻高低拐点。两点高度换算成整数点数后，先检查“ZigZag距离最小值/最大值”（默认 100/10000 点，含边界），再乘“ZigZag止损百分比”（默认 100%）得出止损；止盈为最终止损乘“ZigZag止盈倍数”（默认 1.0）。首单等待波段突破：价格高于两拐点较高价再走一个完整波段高度时视为向上突破，低于较低价再走一个完整波段高度时视为向下突破；“开单方式”正向映射为上破做多、下破做空，反向则相反。未突破时不建仓。超范围、极值不足或经纪商最小止损距离不满足时不创建首单。订单组建立后距离锁定，重启恢复时不根据新的 ZigZag 重算活动组。MT5 图表面板的“距离”页也可编辑这些参数。安装时把 `Indicators/MT4/ZigZag.ex4` 放入终端 `MQL4/Indicators/`，把 `Indicators/MT5/Examples/ZigZag.ex5` 放入 `MQL5/Indicators/Examples/`；同目录提供指标源码。

策略在当前品种没有本EA订单时按设置开首单；随后按循环序列，在当前订单组的外层止损价位准备下一订单组。模式一为“多空空多空空”（首单空时方向取反），模式二为“多空多空多多”（首单空时方向取反），模式三为“多空多多空多”（首单空时方向取反），模式四为“多空空多多空空”（首单空时方向取反）。模式一至三为六阶段循环，模式四为七阶段循环。同向衔接使用限价预挂单，反向衔接使用突破预挂单。

止盈止损距离支持固定距离、上一根已完成K线范围、过去N根K线平均高度、长K线市价和布林带区间模式。箱体高度模式使用品种的 M1 数据，不受当前图表周期影响。时间范围可选滚动回看（默认 12 小时，允许 1 到 720 小时）或每日固定时段（默认服务器时间 01:00 至 12:00）；固定时段只使用最近一个已经结束的区间，边界按开始包含、结束不包含处理，时段可跨午夜。箱体高度为该范围最高价减最低价后换算成整数 points，必须处于“箱体最小高度/箱体最大高度”（默认 500/1000 点，含边界）之间，否则不创建新订单组且不回退到其他距离模式。有效高度同时作为止损和止盈距离；距离在当前订单组/止损切换周期内锁定，新周期重新计算。此模式不增加箱体突破入场条件，首单方向和循环仍按现有设置执行。缺少 M1 历史数据时不创建新组，已有订单和挂单继续管理。选择K线范围模式且“K线开单模式”为“每根一次”时，EA会在上一根已完成K线的最高价和最低价同时预埋首单：开单方式为正向时最高点预埋多单、最低点预埋空单；逆向时最高点预埋空单、最低点预埋多单。一张首单成交后会取消另一张未成交首单，再进入当前订单组的正常管理。选择“每根多次”时仍等待价格突破上一根已完成K线的最高价或最低价后市价开首单。长K线市价模式把上一根已完成K线作为K1，与K2至K21比较最高价减最低价；只有K1长度不小于此前20根中的最大长度且K1不是十字线时才入场，阳线市价做多、阴线市价做空，止损止盈距离使用固定距离参数。布林带区间模式只在当前报价触及布林带上轨或下轨时开首单，方向由“开单方式”决定（正向时上轨做多、下轨做空；逆向时上轨做空、下轨做多）；带内不入场，此时首单方向确定方式由触轨方向决定。止损距离为上轨减下轨的距离乘“布林带止损百分比”，止盈距离再乘“布林带盈亏比”；盈亏比仅在布林带距离模式生效。区间一旦确定，当前订单组后续的预挂单、止损切换、方向和加仓不再因后来布林带变化而中断。参数“开单方式”统一决定K线范围和布林带触轨首单的方向映射，循环方向仍完全使用用户选择的“循环模式”。动态距离必须处于最小值和最大值之间（默认500到1000点），距离一旦确定，当前订单组后续的预挂单、止损切换、方向和加仓不再因后来K线范围变化而中断。边界值包含在有效范围内。固定距离和长K线市价模式使用固定距离参数；平均K线模式使用平均距离参数。参数“止盈移动模式”选择网格移动止盈或线性移动止盈。默认使用网格移动止盈。

网格和订单组手数规则如下：首次建立订单组时直接使用“首单手数”，不乘“首单手数倍数”；订单组止损后，下一订单组首单由“止损首单类型”决定。类型1按此前所有止损订单组总手数之和，再乘“首单手数倍数”（默认1.0）；默认类型2按上一止损订单组首单手数乘“首单类型2倍数”（默认2.0），不包含该组后续网格加仓手数；新增类型3直接使用独立参数“止损首单固定手数”（默认0.01），不乘类型1或类型2的倍数，并适用于止损后直接开单和反向预挂单提前成交。首次新周期仍使用“首单手数”。当前订单组的每个网格单使用固定的该组网格手数，下一组网格手数通常为上一组网格手数乘“网格手数倍数”（默认2.0）；当止损首单类型为2且首单类型2倍数与网格手数倍数相同时，EA以当前组首单手数校准网格手数，避免恢复后的旧状态让两者错位。首组网格手数默认等于首单手数。“网格数量”表示把止损区间分成的格数，默认2，因此内部网格价位为首单到外层止损之间的等分点，外层止损仍负责订单组切换。

“有利方向加单”控制价格向持仓有利方向移动时是否也挂同方向网格单：0为关闭（默认），只在不利方向加单；1为开启，买单上涨或卖单下跌时也按与不利方向相同的“网格数量”和当前组网格手数加单。两侧网格共用当前订单组的止损和止盈管理，不推进六单循环索引。

“动态止损”控制有利方向网格成交后是否移动订单组止损：0为关闭（默认），止损保持在首单锚定价对应的固定位置；1为开启，买单价格每成交一个更高的有利网格层级，止损向上移动一个网格间距，卖单价格每成交一个更低的有利网格层级，止损向下移动一个网格间距。止损移动按已成交的最高有利网格层级计算，不利方向网格成交不会放宽止损；止盈移动规则保持不变。

“v_enable”控制可视化界面：0为关闭（默认），MT5不创建自定义UI，但交易逻辑、定时器、止损恢复和挂单管理继续运行；1为开启，MT5显示当前中文可视化界面。修改后重新加载EA或重新初始化后生效。MT4没有同款自定义UI，该参数仅用于两套EA参数兼容，不影响MT4交易逻辑。

“最大反手次数”限制止损后切换到下一订单组的次数，默认5次；循环中每次止损切换都计数（包括同方向衔接）。达到上限后不再创建下一反手订单组，EA会清理本EA当前品种和订单识别编号下的全部持仓与挂单，清理完成后从下一次Tick重新开始首单流程。设置为0表示首组止损后直接清理并重新开始。

反手订单的总手数会先按未截断的计算结果执行平台限制：总手数小于等于100手时开1笔；大于100手且小于200手时拆成2笔等手数订单，单笔均不超过100手；总手数大于等于200手时停止当前订单组，不发送这笔超大反手订单，清理当前组后从下一次Tick以基础“首单手数”启动新订单组。拆单过程如果第二笔暂时失败，已成交部分会保留，下一次Tick只补足缺少的手数，不重复建立完整订单组。

“K线开单模式”（内部参数名 `Korder_type`）只在距离模式选择“K线高度”时生效：0表示同一根当前K线 k0 只允许创建一次双向首单预埋，首单一侧成交后取消另一侧；1表示同一根 k0 可以按突破条件重复市价开首单。模式0默认开启。模式0在止盈完成后会记住当前k0，当前K线内不会立即按前一根K线重新挂单；检测到新K线时，先删除上一订单组残留的未成交挂单，再检查刚完成的k1高度，只有k1有效才在其最高价和最低价重新挂双向首单，k1无效则等待下一根K线。同一根K线内不会重复创建另一组。模式1保持原有突破后市价开首单逻辑。

“K线多组”只在距离模式选择“K线高度”时生效：0表示保持单订单组，已有持仓或挂单时不建立新组；1表示只要上一根K线高度有效且当前k0突破上一根K线极值，就允许建立新的独立订单组。每个订单组分别锁定自己的K线止盈止损距离、循环、反向预挂单、网格、移动止盈、手数和最大反手次数。“K线开单模式”为每根一次时仍限制同一根k0只触发一次，为每根重复时允许同一根k0重复建立订单组。固定距离模式忽略该参数并保持原逻辑。

“篮子数量”默认1，完全沿用原单篮子开单；设为2时，原首单信号和参数计算不变，EA在同一入场事件中再开等手数、方向相反的首单。两篮子各自锁定止盈止损距离，并独立运行循环、网格、移动止盈和反手逻辑；一篮子止盈结束不会关闭另一篮子。K线每根一次仍先使用原有高低点双向首单挂单，一侧成交后撤销另一侧，再建立反向篮子；“K线多组”仍单独控制不同K线信号能否并行。MT5 设为2或3时必须使用对冲账户。两个初始篮子会使首单总手数和成本预算相应增加。

设为3时，首次仍建立 A、B 两个反向等量篮子。A 确认结束，B 继续运行；B 以后发生原策略允许的止损换单，换单首单实际成交并确认保护后，补建反向篮子 C。C 的首单量等于 B 本次换单首单的实际成交总量，不包含网格量。例如 B 从卖0.01换为买0.03，则 C 从卖0.03开始；B 保留原循环、反手次数和累计亏损，C 从循环首阶段、反手0次、累计亏损0开始。两笔请求先后执行，不能保证同一时刻或同一价格成交。

模式3没有续配代数上限：B 结束后，C 再有效止损换单，可以补出 D。两篮子仍运行时不新增第三篮子；只结束一个篮子但未出现有效止损换单时也不补。相同管理批次的结束与换单统一核对，更晚批次的结束不会追补旧换单事件；仅网格成交、参数重载或风控终止不触发续配。拒单、部分成交、结果未明时保留原事件身份核对，重试只补明确允许的剩余量；重置先清理已成交及晚到的风险，再结束旧意图。

篮子模式按入场时保存。修改参数只影响新的首次入场；已有模式1/2篮子不会被自动转换为3，已有模式3篮子继续按原归属管理。此功能覆盖原全模式版及十种固定距离版本；独立 XAU_NetRR_v2_10 仍保留原1/2规则。

订单组切换采用“已成交不重复、未成交先删除再市价反手”规则：如果止损位置的反向预挂单已经成交，EA先删除旧订单组其余网格挂单，确认清理完成后只处理该成交订单，不再额外执行市价切换；如果止损发生时反向预挂单仍未成交，EA先删除当前订单组的反向预挂单和网格挂单，确认没有残留挂单后立即市价开出下一方向。若反手总手数需要拆单，则按上述规则发送多笔；若删除或发送失败则保留当前状态，下一次Tick重试，避免旧挂单随后成交造成重复开单。

任何反向单或网格单之前，EA都会回读当前订单组的实际止损和止盈。只有止损、止盈都已成功设置且价格与目标一致时，才允许继续挂反向单或网格单；设置失败时只重试保护，不继续增加风险暴露。

市价反手前会持久化“准备切换”阶段和切换标识，成交确认后保存“切换完成”。若终端恰好在两者之间重启，EA先扫描服务器上是否已经存在预期方向和手数的结果仓位：存在则接管，不存在才恢复发送一次，避免重启窗口重复反手。

同一服务器、账户、品种和订单识别编号在同一台电脑上只允许一个EA实例执行交易；策略测试器的锁名额外包含测试图表标识，避免并行回测互相阻塞。单订单组运行时，反向挂单和网格挂单分别按当前订单组预期的方向、价格和手数核对：只保留票据最小的一张正确挂单，错误或重复挂单删除完成后才允许补挂。若已出现多张基础仓位或同一网格价位的重复仓位，EA会撤销该作用域的挂单并暂停新开仓，不自动平掉异常持仓；应先人工核对并处理重复仓位。不同电脑之间不能共享本地实例锁，因此跨电脑运行时仍必须使用不同的订单识别编号。

若重启后检测到无持仓但仍有残留挂单，EA会先按已保存订单组状态核对并清理错误或重复挂单；若订单组状态已经无法恢复，则删除该作用域全部残留挂单并清空旧状态，只允许从下一次Tick重新进入首单流程。

订单组止盈止损距离在组内锁定。首单成交后预挂同向网格单；每个网格层级在当前订单组内只允许成交一次，EA会根据已成交持仓的网格层级恢复记录，避免因票据缓存或成交量状态失步而在同一价位反复补挂。动态止损关闭时，当前组所有持仓的止损保持在首单锚定价对应的外层止损；动态止损开启且有利网格成交后，持仓和仍有效的网格挂单同步到新的止损位置，已经落入新止损线内的不利网格挂单会被撤销。网格移动止盈模式下，有利方向网格加单沿用当前订单组止盈，不推动止盈；不利方向网格加单沿用当前止损，并将止盈移动到该笔网格成交价加/减原止盈距离。若动态止损已因有利方向加单上移，后续不利方向加单不会使止损回退；线性移动止盈模式下，只要价格向当前订单组的不利方向移动，止盈就按相同点数向不利方向移动，价格反弹时止盈不回退。网格加单不会推进六单循环索引。止盈后删除剩余挂单、清空亏损累计并结束本轮。

参数说明：“首单方向”为使用预设方向的距离模式首单方向；“首单方向确定方式”选择“预设方向”时使用它，选择“布林带判断”时使用当前买卖价中间价与当前K线布林带中轨比较，上方做多、下方做空，贴近中轨时等待下一次价格变化。“开单方式”同时控制K线突破和布林带触轨首单方向：正向时上轨做多、下轨做空，逆向时上轨做空、下轨做多；“布林带周期”默认20，“布林带标准差”默认2.0；“循环模式”为所有单组模式均使用的循环方式，模式四为七阶段“多空空多多空空”（首单空时取反）；“距离模式”为止盈止损距离来源；“开单方式”为K线范围和布林带距离模式共用的正向或逆向方向映射；“K线开单模式”为每根K线一次创建双向首单预埋或允许重复市价首单；“K线多组”为K线高度模式是否允许多个订单组并行；“止盈移动模式”为网格或线性移动止盈方式；“首单手数”为首轮订单组的原始首单交易量；“止损首单类型”为止损后首单计算方式，1为累计订单组总手数、2为上一组首单倍数、3为指定固定手数；“首单类型2倍数”为类型2的上一组首单倍数；“止损首单固定手数”为类型3专用固定交易量；“有利方向加单”为是否在有利方向按相同网格数量加单；“动态止损”为是否按已成交的最高有利网格层级移动止损；“v_enable”为MT5自定义可视化界面开关，0关闭、1开启；“首单手数倍数”为类型1下订单组止损后下一组首单交易量的倍数；“最大反手次数”为止损后允许切换订单组的最大次数；“网格数量”为止损区间等分格数；“网格手数倍数”为下一订单组网格手数倍数；“固定止损距离”和“固定止盈距离”为固定模式下的距离点数；“K线最小高度”和“K线最大高度”为K线范围限制；“订单识别编号”为识别本EA订单的编号；“订单注释”为发送到交易平台的订单说明。

“开始时间”和“结束时间”作为时段1，用于限制首单开仓时间；另有“时段2开始时间/时段2结束时间”和“时段3开始时间/时段3结束时间”。三个时段均按交易平台服务器时间判断，当前时间命中任意一个启用时段即可开首单，默认时段1为每天08:00至23:00，时段2和时段3关闭。每个时段支持跨午夜；精确的00:00-00:00表示关闭，非零的相同开始和结束时间表示全天。有效时间之外只禁止空仓且无挂单时开首单；已有持仓、反向预挂单和网格预挂单均不受影响。

如果市价单因为资金不足被拒绝（MT5错误码10019，MT4对应资金不足错误），EA会删除本EA当前品种和订单识别编号下的全部反向预挂单、网格挂单，并关闭全部多空持仓；清仓未完成前禁止开新单。清仓完成的当前Tick直接结束，下一次Tick才重新执行首单流程。重新开始时累计亏损手数、循环索引、网格状态和旧订单组距离全部清空；固定距离模式重新检查有效操作时间，K线高度模式重新检查当时上一根K线的高度和突破条件，首单使用基础“首单手数”。

这是递增手数策略，连续止损会快速增加风险，请先在模拟盘和策略测试器中验证经纪商的最小手数、手数上限、止损距离、保证金条件，以及MT5账户的净持仓/对冲模式差异。

箱体确认突破是独立于现有箱体高度距离模式的新模式。默认在当前图表周期扫描最近60根已收盘K线，以窗口高低点作为候选边沿，并使用14周期ATR的0.2倍作为触碰容差；要求上下沿各触碰至少2次、至少2次完整往返、同侧事件间隔至少3根，宽度须为500至1000点（含边界）。确认后冻结边沿和0.2倍确认ATR突破缓冲；连续两根收盘价越过边沿及缓冲才按开单方式映射方向市价开单。箱体宽度同时作为首单止损和止盈距离，订单组内锁定。箱体在确认后经过60根新K线仍未突破则过期；历史数据不足时等待。

## 独立固定模式 EA

除原有的 `NoMatterRiseFall_MT4` / `NoMatterRiseFall_MT5` 全模式兼容版外，本目录提供十种独立策略入口。每个入口都单独编译；订单组、网格、止盈、止损、反手与风控逻辑仍由平台公共核心维护。固定模式版不提供“距离模式”切换，其 MT5 面板会显示固定 EA 名称，并只显示该模式可用的参数。

| EA | 模式参数 | MT4 默认 Magic | MT5 默认 Magic |
|---|---|---:|---:|
| FixedDistance | 首单方向与判定方式、布林带周期/标准差、固定止损/止盈距离 | 2026101101 | 2026101109 |
| CandleHeight | 开单方式、每根 K 线开单模式、多组开关、K 线最小/最大高度 | 2026101102 | 2026101110 |
| AverageCandleHeight | 首单方向与判定方式、布林带周期/标准差、平均 K 线根数和止损/止盈倍数 | 2026101103 | 2026101111 |

| BollingerRange | 布林带周期/标准差、开单方式、止损百分比、盈亏比、最小/最大止损距离 | 2026101105 | 2026101113 |

各 EA 还保留公共循环、篮子、首单手数、止损后首单类型、最大反手次数、点差限制、止盈移动、网格、动态止损、Magic/订单注释和三个交易时段参数。MT5 另外保留 `v_enable`；MT4 固定模式版没有该参数。默认 Magic 在模式和平台之间均不重复，可在同一账户、同一品种上并行运行。不要把两个实例改成相同账户/品种/Magic；同一订单作用域只允许一个活动管理者。

MT4 输入页和 MT5 图表面板均只呈现固定模式相关设置。MT5 面板以只读的 EA 模式名称标识入口，不提供距离模式选择。原全模式版继续保留在原文件名，供旧模板和现有订单组兼容运行。

用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\compile-mql.ps1 -Profile All -Target Both` 编译全部 20 个独立 EA。运行 `scripts/package-distance-mode-eas.ps1` 后，安装包生成在 `dist/DistanceModeEAs/<模式>/MT4|MT5/Experts`；只有 ZigZagSwing 包含 ZigZag 指标文件。

从旧全模式版迁移时，让旧 EA 继续管理活动订单组，待其空仓后再挂对应固定模式版，并使用该版本的默认 Magic。固定模式 EA 遇到同一 Magic 下的旧状态、其他模式状态或无归属持仓/挂单会拒绝初始化，不会认领、平仓或接管这些订单。旧全模式版与固定模式版的策略行为请分别回测并在模拟盘核对；更换模式时重新检查该入口的专属参数。

新增模式说明：[均值两倍K线](README_AverageDoubleCandle.md)、[布林带宽度倍增](README_BollingerExpansion.md)。两种模式的触发倍数都可调整，默认2.0；均值两倍K线也提供正向/逆向开单方向选择。布林带宽度倍增默认使用刚收盘线，对此前20根带宽均值比较；默认初始止盈止损各取信号带宽25%，也支持固定点数。它的距离子模式只选择初始距离来源，不切换开单策略。原生输入页静态保留两种距离字段，MT5图表面板按子模式切换显示。

# 均值两倍 K 线 EA（第九种独立模式）

MT4 和 MT5 各有独立入口，共用各平台原有订单管理核心。

## 开单条件

使用当前图表周期刚收盘的 K 线，长度为最高价减最低价（包括上下影线）。设该信号线长度为 L，其之前 N 根已收盘 K 线的平均长度为 A：

`L >= 均值触发倍数 × A`

满足条件后，默认阳线开买单、阴线开卖单，十字星不开。“开单方式”默认正向，可切换为逆向，使阳线开卖单、阴线开买单。均值不包含信号线和当前未收盘线。N 默认 20，可在“平均K线根数”中调整，范围为 1–10000；“触发倍数”默认 2.0，必须为有限正数。当前K线长度达到“前N根平均长度×触发倍数”时开单。

同一根信号线只尝试启动一次。首单被拒绝或本轮结束后，也不会在同根信号线上逐 tick 重试。历史不足或价格数据无效时等待有效数据。

## 止盈止损距离

“止盈止损距离(%)”默认 50%，可调整为正数：

`初始止盈距离 = 初始止损距离 = L × 百分比 / 100`

距离按品种的报价点四舍五入为整数点，至少为 1 点。比如信号线长度为 10 美元、百分比为 50%，初始止盈和止损距离均为 5 美元。该距离是相对开仓价格的价格差。

信号确认时锁定订单组距离，后续反手、网格等沿用该组距离，不使用新的 K 线重新计算。移动止盈、动态止损开启后，保护价格仍按原有规则调整。

## 保留的公共逻辑

循环、反手、网格、有利方向加单、移动止盈、动态止损、风控、交易时段、首单过滤及单/双订单组继续由公共核心维护。启用这些功能后，一次信号可能按设置产生后续订单；“同根只尝试一次”约束的是初始信号，不会禁用明确配置的双组和后续订单。

输入页和 MT5 图表面板仅提供本模式的 N、距离百分比及公共参数，不提供其他距离模式切换。

## 安装与隔离

将对应平台包中 `Experts` 内的 `.ex4` 或 `.ex5` 放入终端的 Experts 文件夹。源码和 `.mqh` 同时提供，重新编译时需放在同一目录。

- MT4 默认订单识别编号：2026101801。
- MT5 默认订单识别编号：2026101802。

不同模式已有不同默认编号。在同一账户、同一品种运行多个实例时，每个实例使用不同编号，避免手动改成相同值。原有作用域占用及订单归属检查仍保留。

验证记录见 `validation/average-double-candle-2026-10-18/README.md`。交付包含源码和 MQL 字节码，不是 Windows EXE。

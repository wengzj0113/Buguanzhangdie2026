# 布林带宽度倍增 EA（第十种独立模式）

## 开单规则

使用当前图表周期刚收盘的 K1，布林带宽度 W1=上轨−下轨。将此前 K2 至 K(N+1) 各自的布林带宽度取平均值 A：

`W1 >= 带宽触发倍数 × A`

满足该条件才允许启动首单，同时仍需通过原交易时段、点差、账户风控等公共检查。均值不包含 K1 或当前未收盘线。

“平均带宽根数”默认20，可调1至10000；“触发倍数”默认2.0，可设为有限正数。当前带宽达到“前N根平均带宽×触发倍数”时开单。它们与“布林带周期”相互独立；布林带周期默认20（范围2至10000），标准差默认2.0，应用于收盘价。

首单方向沿用原核心设置：预设做多/做空，或者按当前价格相对布林带中轨判断。默认预设做多。此模式不要求触碰上轨或下轨，不使用 K 线涨跌方向决定买卖。

## 初始止盈止损距离

“带宽距离模式”提供两种选择：

| 模式 | 初始止损距离 | 初始止盈距离 |
| --- | --- | --- |
| 带宽百分比（默认） | W1 × 带宽距离百分比 | W1 × 带宽距离百分比 |
| 固定点数 | 固定止损距离 | 固定止盈距离 |

“止盈止损百分比(%)”默认25%，可设为有效正数。百分比计算取开单信号时 K1 的布林带宽度，换算为报价点后四舍五入，至少1点。例如上下轨相差20，25%对应初始止损和止盈各相距5。

固定止损、固定止盈默认均500点，可分别设置不同值。单位是品种报价点 `_Point`，不是美元金额或固定的 pip。固定模式忽略百分比值，但仍必须通过带宽倍增开单条件。

在信号确认时锁定组内初始距离；后续 K 线的带宽不会覆盖该距离。移动止盈、动态止损开启后，保护价格继续按原规则变化，因此后期保护价不要求与初始距离相同。

## 原有公共功能

循环、反手、网格、有利方向加单、手数、最大反手次数、移动止盈、动态止损、交易时段、风险过滤、单/双订单组均沿用公共核心。带宽倍增只判断初始开单，不重新过滤原流程内的网格或反手。

每根信号线最多消费一次初始流程，首单拒绝或订单组结束后同根也不再次尝试，且中轨方向变化不会绕过锁。明确启用双组时仍按一次信号启动正反两组。下一根信号线若仍满足条件，可按公共规则再次启动，不额外要求带宽先收窄。

## 安装、输入与隔离

MT4、MT5各有独立入口，将各自 `Experts` 内 `.ex4` / `.ex5` 复制到相应终端的 Experts 目录。源码和 `.mqh` 同时提供；重新编译需保持它们在同一目录。

- MT4 默认订单识别编号：2026101811。
- MT5 默认订单识别编号：2026101812。

同账户、同品种运行其他模式或多个实例时，每个实例保持不同订单编号。MT5双组沿用原对冲账户要求。

MT5图表面板随距离模式切换显示百分比或固定距离。MT4/MT5原生输入页采用静态参数列表，因此两种模式参数都保留；只读取所选距离模式对应的值。

验证记录：`validation/bollinger-expansion-2026-10-18/README.md`。交付文件为 MQL 字节码，不是 Windows EXE。

# 不管涨跌 EA · XAU 净盈亏比版 2.10

此版本以独立文件交付 MT4 和 MT5；原版 `NoMatterRiseFall_MT4.*`、`NoMatterRiseFall_MT5.*` 保留。新版文件名包含 `XAU_NetRR_v2_10`，运行前请确认平台、源码与编译文件的版本一致。

## 解决的问题

新版增加可选的 XAUUSD 成本控制模式。在增加仓位之前，用当前 Bid/Ask、允许的开仓价格、佣金及手续费预算、平仓滑点预算，估计整轮交易在止盈和止损时的账户货币净结果。预计净盈亏比不达标、点差过大、报价过期或风险超过上限时，跳过新增仓位。已有仓位的服务器止损仍须保留。

买单按 Ask 开仓、Bid 平仓，卖单按 Bid 开仓、Ask 平仓。实际成交价已经反映当时点差，净结果计算不能再额外扣一次点差。已经入账的佣金、手续费及隔夜费应计入实际账本；尚未入账的费用按预算保留。

## 启用前

1. 在对应平台加载带 `XAU_NetRR_v2_10` 标识的 EA，核对图表品种为 XAUUSD；不同经纪商的黄金后缀品种需按 EA 的品种校验规则处理。
2. 用目标账户的合约规格、最小价格跳动、真实点差、每手往返佣金与历史滑点，填写成本预算。点数取该经纪商报价的 `Point`，不是固定的美元金额。
3. 先在完全空仓、没有该 EA 旧挂单时启用成本模式。运行中的旧轮次不能直接切换算法。不要让原版和新版使用同一个品种与订单识别编号同时交易。
4. MT5 成本模式按对冲账户设计；净持仓账户不能运行多独立订单组的成本账本。
5. 用目标经纪商的真实 Bid/Ask Tick 和样本外区间比较净收益、回撤、拒单率及实际滑点，再考虑模拟盘验证。

## 结果边界

目标盈亏比是**下单前的预算门槛**，不是实际成交保证。跳空、断线、服务器止损滑点、延迟费用以及经纪商执行模式都可能让最终盈亏比低于目标。虚拟开仓触发器依赖终端在线和 EA 正常运行；持仓保护仍依赖服务器端止损。成本模式不会为了凑目标无上限地推远止盈，也不会扩大止损。

此仓库没有目标经纪商的 XAUUSD 真实 Tick、佣金账单和模拟账户日志，因此不能仅凭编译或单元测试认定该版本在实盘盈利，或给出统一适用的点差/滑点数值。

## 双篮子开单

“篮子数量”默认1，沿用原单篮子逻辑；设为2时，同一入场信号再开一笔手数相同、方向相反的首单。两个篮子分别维护止盈止损、网格、循环、反手和成本账本；一个篮子止盈结束后另一个继续运行。K线每根一次仍先保留原高低点首单挂单和一侧成交后撤销另一侧的规则。双篮子会提高总开仓量和交易成本，成本模式必须先按两边合并检查单轮及全轮风险预算；MT5 需要对冲账户。更改参数只影响新入场事件，不会为运行中的旧组补单。
